# WEJO App

WEJO 팀의 웹 서비스 개발 저장소입니다. `wejo-app`은 임시 저장소 이름이며 서비스 이름은 아직 정하지 않았습니다.

현재 프론트·백엔드 실행 기반, 비동기 PostgreSQL 연결, health API, 앱 CI와 문서 사이트·Wiki 자동 게시 구성을 제공합니다. 실제 서비스 기능·인증·앱 운영 배포는 아직 구현하지 않았습니다.

- [문서 인덱스](docs/README.md): 작업에 필요한 문서만 선택해서 읽습니다.
- [WEJO 문서 사이트](https://wejo-team.github.io/wejo-app/): 검색·목차·모바일 메뉴를 제공하며, `main` 병합 후 Pages 배포가 성공하면 갱신됩니다.
- [로컬 실행](docs/development/local-development.md): 설치·실행·검사 명령입니다.
- [GitHub Wiki](https://github.com/wejo-team/wejo-app/wiki): 같은 문서의 Wiki 게시본입니다.
- [개발 가이드](docs/development/README.md): 기술 선택과 영역별 규칙입니다.
- [팀 작업 흐름](docs/development/workflow.md): 명세 검토부터 개발 계획·구현·리뷰까지의 절차입니다.
