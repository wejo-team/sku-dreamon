# 서경드림온

WEJO 팀이 만드는 **서경드림온**의 개발 저장소입니다. 학생들이 공모전을 통해 잠재력과 꿈을 밝히고 지속적인 도전을 이어간다는 의미를 담고 있습니다. 약칭은 **드림온**, 영문 표기는 **SKU DreamOn**입니다.

현재 프론트·백엔드 실행 기반, 비동기 PostgreSQL 연결, health API, 앱 CI와 문서 사이트 자동 게시 구성을 제공합니다. 실제 서비스 기능·인증·앱 운영 배포는 아직 구현하지 않았습니다.

- [문서 인덱스](docs/README.md): 작업에 필요한 문서만 선택해서 읽습니다.
- [이름과 표기](docs/branding.md): 서경드림온의 의미와 서비스명·기술 식별자 표기 기준입니다.
- [서경드림온 문서 사이트](https://wejo-team.github.io/wejo-app/): 검색·목차·모바일 메뉴를 제공하며, `main` 병합 후 Pages 배포가 성공하면 갱신됩니다.
- [로컬 실행](docs/development/local-development.md): 설치·실행·검사 명령입니다.
- [개발 가이드](docs/development/README.md): 기술 선택과 영역별 규칙입니다.
- [팀 작업 흐름](docs/development/workflow.md): 명세 검토부터 개발 계획·구현·리뷰까지의 절차입니다.
