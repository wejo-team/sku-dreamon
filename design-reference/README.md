# 서경드림온 이전 디자인 레퍼런스

초기 모바일 화면과 모의 인터랙션을 보관한 독립 실행 앱입니다. 현재 화면·인터랙션의 기준은 `frontend/`이며 [제품 UI 안내](../docs/design/README.md)에서 화면 소스와 스타일을 확인합니다. 이 앱의 수정·제품과의 동기화는 개발 선행 조건이 아닙니다.

이 앱의 입력 계약·프로필 공개 조건·주당 시간·공고와 팀 정원·AI 검토·알림은 [선행 문서 PR #93](https://github.com/wejo-team/sku-dreamon/pull/93) 이후 반영한 디자인 이력입니다. 최신 제품 정책과 구현 상태는 각 기능 명세에서 확인합니다.

로컬 확인 계정은 `dreamondemo` / `DreamonReview2026!`입니다. 공개된 UI 확인용 고정 문자열이며 실제 계정·인증 비밀이 아닙니다.

과거 화면을 재현할 때만 [이전 개발 인계](../docs/design/handoff.md)의 실행 방법과 테스트 계정을 확인합니다. 이 앱은 메모리의 예시 데이터와 모의 응답으로 동작하며 실제 인증·API·LLM을 연결하지 않습니다.
