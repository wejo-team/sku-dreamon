# 서경드림온 공식 디자인 레퍼런스

모바일 화면과 인터랙션을 확인하는 독립 실행 앱입니다. 프론트엔드 개발의 디자인 기준은 이 저장소의 코드와 [공식 디자인 안내](../docs/design/README.md)이며 GPT Sites 배포본은 기준 원본이 아닙니다.

입력 계약·프로필 공개 조건·주당 시간·공고와 팀 정원·AI 검토·알림은 [선행 문서 PR #93](https://github.com/wejo-team/sku-dreamon/pull/93)과 담당 명세를 기준으로 합니다. 신규 지원은 공개 프로필만 가능하며, 이후 비공개 전환해도 기존 지원과 해당 팀장의 최신 프로필 기반 AI 검토는 유지합니다.

로컬 확인 계정은 `dreamondemo` / `DreamonReview2026!`입니다. 공개된 UI 확인용 고정 문자열이며 실제 계정·인증 비밀이 아닙니다.

실행 방법, 테스트 계정, 화면별 명세와 제품 구현으로 옮기는 방법은 [개발 인계](../docs/design/handoff.md)를 확인하세요. 이 앱은 메모리의 예시 데이터와 모의 응답으로 동작하며 실제 인증·API·LLM을 연결하지 않습니다.
