# 제품 UI와 디자인 기록

현재 화면·인터랙션의 기준은 **`frontend/`의 제품 코드**입니다. 이 폴더는 화면 소스 안내, 공통 스타일과 자산 출처, 이전 디자인 검증 기록을 관리합니다. 기능 동작·정책은 [기능 명세](../specs/README.md), 개발 절차는 [팀 작업 흐름](../development/workflow.md)을 따릅니다.

| 문서 | 읽는 시점 |
| --- | --- |
| [화면과 기능 명세](screens.md) | 담당 제품 화면의 경로·소스·정상/예외 상태와 관련 정책을 찾을 때 |
| [스타일과 컴포넌트](tokens.md) | 제품의 공통 토큰·모바일 배치·UI 컴포넌트를 적용하거나 변경할 때 |
| [로고·마스코트 이미지 출처](assets.md) | 제품 로고·프로필 캐릭터·공모전 기본 이미지를 사용하거나 교체할 때 |
| [UI 검증 기록](verification.md) | 날짜·대상 앱별 검증 범위와 스크린샷을 확인할 때 |

제품 실행은 [로컬 실행](../development/local-development.md), 화면 구현 규칙은 [프론트엔드 가이드](../development/frontend.md)를 확인합니다. UI 변경은 제품 화면·관련 명세·검증 자료를 함께 갱신하며, 별도 레퍼런스 앱을 먼저 수정하거나 같은 화면을 동기화할 의무는 없습니다.

## 보관한 디자인 이력

초기 화면·모의 동작을 담았던 `design-reference/` 디렉터리는 2026-11-01 사용자 요청으로 삭제했습니다. [삭제 전 소스](https://github.com/wejo-team/sku-dreamon/tree/7f1ac30ddbba4c169582992730fbf51be3de30d7/design-reference)는 Git 이력에서 확인하며 최신 제품 화면·정책·API 계약의 기준으로 사용하지 않습니다.

- [이전 개발 인계](handoff.md): 레퍼런스 실행법, 모의 구현의 범위와 당시 제품 이관 기록
- [디자인 기능·명세 대조 기록](../specs/prototype-alignment.md): 이전 정책 반영·배포 이력
