# 공식 디자인 검증 기록

2026-10-18 저장소 이관과 기능 명세 정합 작업에서 확인했습니다. 재생성 가능한 검증 원본은 [단위·컴포넌트 테스트](../../design-reference/src/features/design-preview/ExplorePages.test.tsx)와 [브라우저 검사 스크립트](../../design-reference/scripts/reference-check.cjs)이며, 화면은 같은 변경 PR에 포함된 코드 기준입니다.

## 실행 결과

| 검사 | 결과 |
| --- | --- |
| 고정 의존성 `npm ci` | 성공 |
| `npm test` | 8개 파일, 101개 테스트 통과 |
| ESLint·Prettier·TypeScript | 통과 |
| production build | 성공. 단일 JS 청크 약 670kB 경고는 남아 있으며 제품 구현 시 분할·실제 네트워크 성능 검증 필요 |
| `npm run check:ui` | Chromium 320×844·390×844·430×844 통과 |
| 브라우저 확인 | 비로그인 사람 차단, 마감 공고 읽기 전용, 생성·프로필, 선발 즉시 팀원·정원 반영, AI 실패/재시도, 알림 실패/재시도 |
| 별도 모바일 흐름 | 필수 입력 오류·원래 팀 복귀, 모집에 없는 역할 지원, 취소 후 새 지원, 공식 인원 오류, 개인 공모전 준비 팀, 공개 스위치·학사 연쇄 선택·포트폴리오 저장 |
| 레퍼런스 화면 | 확인한 폭에서 가로 넘침·브라우저 런타임 오류 없음 |
| 문서 | 원본 링크·앵커, 문서 도구 테스트, VitePress 빌드·생성 링크·자산 검사 통과 |

브라우저 검사는 설치된 Playwright/Chromium을 환경 변수로 지정해 실행했습니다. 일반 설치·실행과 CI 명령은 [인계 문서](handoff.md#verification-commands)를 따릅니다. 실제 기기의 키보드·보조 기술, 서버 권한, 다중 사용자 동시 선발, 영구 저장과 실제 LLM 품질은 검증 대상이 아닙니다. 이 결과는 기능 명세 AC의 제품 구현 완료를 의미하지 않습니다.
