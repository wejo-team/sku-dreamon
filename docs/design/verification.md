# 공식 디자인 검증 기록

2026-10-18 저장소 이관·기능 명세 정합 작업 이후, 로고·마스코트 선택·기본 커버에 이어 카드 대비·탐색 아이콘과 필터 팝업·키/값 정보 계층을 검토했습니다. 재생성 가능한 검증 원본은 [단위·컴포넌트 테스트](../../design-reference/src/features/design-preview/ExplorePages.test.tsx)와 [브라우저 검사 스크립트](../../design-reference/scripts/reference-check.cjs)이며, 화면은 같은 변경 PR에 포함된 코드 기준입니다.

| `npm run check:ui` | Chromium 320×844·390×844·430×844 통과. 기존 흐름에 필터 취소·적용·초기화와 워크스페이스 중복 안내 제거 확인을 추가 |

| 별도 모바일 흐름 | 필수 입력 오류·원래 팀 복귀, 모집에 없는 역할 지원, 취소 후 새 지원, 공식 인원 오류, 개인 공모전 준비 팀, 공개 스위치·학사 연쇄 선택·포트폴리오 저장 |
| 마스코트·기본 커버 | 5종 원본 PNG·선택/취소/저장·공개 프로필 반영, 이미지 없음/로드 실패 fallback, 320·390·430px 브라우저 확인 |
| 키보드·작은 높이 | 마스코트·탐색 필터의 화살표 키·Escape·트리거 포커스 복귀 확인. 320×568에서 두 선택 목록의 스크롤·하단 버튼 접근, 탐색 필터 적용·취소 확인 |
| 색상 대비 | 주요 버튼 흰 글자 5.36:1. 카드 보조 글자 #40594a는 기본·hover·누름 면에서 5.92:1·5.07:1·4.61:1, 흰 조작 면의 기본 보조 글자는 6.07:1. 모든 화면 전체의 자동 접근성 감사 완료를 뜻하지 않음 |
| 카드와 배경 | 기존 중립 회색 배경 #f1f1f3 유지, 카드 #d4e7db·hover #bdd9c7·누름 #b2d0bd, 아래쪽 그림자·흰 정보 면을 적용 |
| 탐색 필터 | Drawer 초안 선택 후 취소 시 URL 유지, 적용 시 URL 반영·다시 열기 복원. 정렬만 변경해도 초기화 아이콘으로 기본 조건 복원하는 컴포넌트 테스트 통과 |
| 정보 계층·중복 안내 | 공모전·공고·내 프로필·공개 프로필·워크스페이스·팀 공간·지원자 검토 7개 경로를 320·390·430px에서 확인. 키 13px/500, 값 16px/600, 긴 설명 16px/400. 팀 목록 중복 정원 문구 제거와 기존 정원 정책 유지 |
| 레퍼런스 화면 | 확인한 폭에서 가로 넘침·브라우저 런타임 오류 없음 |
| 문서 | 최신 스크린샷을 포함한 원본 링크·앵커, VitePress 빌드·생성 링크·자산 검사 통과. 문서 도구는 변경하지 않아 이전에 통과한 도구 테스트는 재실행하지 않음 |

브라우저 검사는 설치된 Playwright/Chromium을 환경 변수로 지정해 실행했습니다. 일반 설치·수동 실행 명령은 [인계 문서](handoff.md#verification-commands)를 따릅니다. 실제 기기의 키보드·보조 기술, 서버 권한, 다중 사용자 동시 선발, 영구 저장과 실제 LLM 품질은 검증 대상이 아닙니다. 이 결과는 기능 명세 AC의 제품 구현 완료를 의미하지 않습니다.
