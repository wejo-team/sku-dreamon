# AI 에이전트 SDD

- 기준: 2026-10-25 사용자 결정, [설계 Draft PR #156](https://github.com/wejo-team/sku-dreamon/pull/156)
- 상태: **백엔드 작업 브랜치 구현 · 프론트 미구현 · 미배포**
- 기준 명세: [LLM 기반 추천](../specs/matching.md#acceptance-criteria), AC-16~34
- 계약 원본: [AI API](../api/ai.md), [AI 실행 저장](../database/ai.md)
- 현재 작업 범위: 사용자가 계획대로 구현을 요청한 뒤 **백엔드만 구현**으로 한정. 후속 요청으로 구현 변경을 커밋·푸시하며 운영 DB 적용은 범위 밖

공모전·팀·공개 사람 탐색과 팀장의 지원자 검토를 기존 FastAPI 서비스에 연결합니다. 사용자 동작은 기능 명세, 전송 계약은 DTO·API 문서, 저장 구조는 ORM·DB 문서가 원본입니다. 프론트의 로그인·대화·지원자 화면은 기존 모의 동작을 유지하며 이번 구현 완료 범위가 아닙니다.

## 결정과 적용 범위

| 항목 | 선택 | 적용 상태 |
| --- | --- | --- |
| 에이전트 | `langchain.agents.create_agent`, LangGraph 런타임 | 구현 |
| 모델 | OpenAI Luna, `gpt-6-luna` | 실제 도구 호출·구조화 출력·스트림 수동 검증 |
| 모델 API | Responses API, `store=False`, 자동 모델 대체 없음 | 구현 |
| 응답 전달 | FastAPI 비동기 실행과 POST SSE | 백엔드 구현, 화면 연결은 후속 |
| 대화 유지 | 현재 브라우저 탭 메모리, 새로고침·새 대화·로그아웃 시 초기화 | 제품 요구사항. 서버 복원 API·원문 저장 없음 |
| 실행 상태 | PostgreSQL 공유 메타데이터·입력/결과 해시·근거 참조 | 모델·migration·재시도·중단·정리 구현 |
| 프론트 | 로그인·탭 메모리·스트림 파서·복사 재검증 | 사용자 요청에 따라 이번 구현에서 제외 |

별도 LLM worker·큐·LangGraph 서버·Deep Agents·벡터 DB·임베딩·장기 기억은 도입하지 않습니다. 자동 지원·선발·외부 웹/포트폴리오 수집·과거 대화 목록은 기존 제외 범위를 유지합니다.

## 실행 구조

```text
인증된 클라이언트의 POST 요청
    │
FastAPI 라우터: 쿠키·CSRF·DTO 검증 / SSE 직렬화·연결 수명
    │
AI 서비스: 목적·소유권·예산·현재 시도 / 결과 검증
    ├─ create_agent: 허용된 조회 도구 → 구조화된 후보·근거
    │      └─ 자료 서비스 → 기존 도메인 서비스 → repositories → PostgreSQL
    ├─ 서버 검증: 실제 ID·현재 관계·후보 조건·개수·근거 해시
    └─ Luna 답변 작성 → 전송 직전 재검증 → 텍스트 조각·결과·종료
```

요청 프로세스에서 비동기로 실행하고 연결 종료 시 하위 작업을 정리합니다. 프로세스 장애 후 이어서 실행하거나 SSE 이벤트를 재생하지 않습니다. 후보 선정은 여러 모델 호출이 필요할 수 있으며, 답변 작성은 도구 없는 별도 모델 호출입니다. 첫 텍스트 전에는 진행 이벤트를 제공합니다. 이 분리는 검증 전 도구 출력·내부 계획이 제품 스트림에 섞이는 것을 막지만 첫 텍스트까지의 지연과 추가 호출 비용이 있습니다.

## 목적별 도구와 권한

| 목적 | 조회 범위 | 서버 검증 |
| --- | --- | --- |
| `chat` | 공개 공모전·현재 추천 가능한 팀·공개 사람 | 비공개 본인 프로필 자동 읽기 금지. 지원자 검토 권한을 일반 대화로 확대하지 않음 |
| `applicant_review` | 현재 팀장이 받은 지원 한 건과 최신 프로필 | 경로의 대상에 고정. 마감·정원·지원 뒤 비공개·종결 상태만으로 기존 검토를 거절하지 않음 |
| `applicant_recommendation` | 자기 팀의 유효 지원 | 새 후보는 지원 완료·검토 중이고 같은 공모전 소속이 없음 |

모델에 SQL·범용 HTTP·쓰기 도구를 주지 않습니다. 계정·세션·팀장 관계·고정 대상은 서버 컨텍스트로 주입합니다. 일반 팀 추천은 모집·마감·정원뿐 아니라 같은 공모전 소속·같은 팀의 유효 지원과 미선발 이력을 검사합니다. 기존 지원자 검토를 시작하거나 다시 요청해도 지원 상태·정원·소속·알림을 변경하지 않습니다.

전송 필드는 [자료 서비스](../../backend/app/services/ai_sources.py)의 허용 목록으로 제한합니다. 프로필은 이름·소개·분야/역할·역량·경험 상태/본문·주당 참여 가능 시간, 공고는 설명·접수 일정·원문 자격·인원·제출물/시상, 팀은 소개·모집 역할·현재 모집 정보, 지원은 지원 메시지·역할·상태와 관련 팀/프로필을 사용합니다. 학사 항목·인증 값·연락처 전용 필드·포트폴리오 링크/외부 내용은 모델 입력에 넣지 않습니다.

소개·공고·지원 메시지에 포함된 지시는 권한을 바꾸지 못하는 데이터로 취급합니다. 제목·실제 ID·`isDemo`·프로필 버전은 서버 자료로 조립합니다. 구조화 출력은 형식 검증이며 설명의 사실성·추천 품질 전체를 보장하지 않습니다.

## 대화 맥락과 저장

클라이언트는 현재 사용자 입력, 이전 사용자 발화, 이전 실행 참조만 보냅니다. assistant·system·developer·tool 메시지를 과거 사실 근거로 받지 않습니다. 이전 실행은 소유 세션·같은 대화·시도를 확인하고 선택된 실제 자료를 현재 권한으로 다시 조회합니다. 공개가 철회된 과거 본문을 모델에 재전송하지 않습니다. 사용자가 직접 자유 텍스트에 넣은 정보까지 서버가 출처를 증명하는 구조는 아닙니다.

| 위치 | 정보 | 수명 |
| --- | --- | --- |
| 요청 메모리 | 사용자 맥락·도구 자료·계획·생성 중 답변 | 실행 동안. 사용자별 실행 상태를 공유 모델 객체에 저장하지 않음 |
| PostgreSQL | 소유 세션·식별자·목적·시도·상태·기한·입력/결과 SHA-256·근거 ID/버전/해시 | 기본 24시간 뒤 접근 만료. 새 요청 또는 운영 정리 명령에서 삭제 |
| 앱 로그 | 실행 ID·시도·목적·종료 이벤트·소요 시간·안전한 예외 종류 | 대화·프로필·도구 원문·제공자 오류 문자열 제외. 운영 로그 보존은 배포 설정 |
| 브라우저 | 현재 표시 결과와 원래 결과·실행 참조 | 현재 탭 메모리 요구사항. 이번 백엔드 작업에서 UI를 변경하지 않음 |

LangGraph 영속 checkpointer·store를 연결하지 않습니다. OpenAI 호출에서 응답 저장을 끄고 LangSmith tracing을 비활성화합니다. `store=False`가 제공자의 모든 로그·보존이 없다는 의미는 아닙니다. [OpenAI 데이터 정책](https://developers.openai.com/api/docs/guides/your-data)

지원자 검토도 원문을 서버에 보존하지 않습니다. 클라이언트가 현재 탭에 가진 결과를 서버의 결과 해시와 대조한 뒤 최신 권한·프로필 버전을 검사합니다. 전체 메시지·최신 검토 원문을 서버에서 복원하는 GET은 제공하지 않습니다.

## 스트리밍·재시도·현재 권한

정상 이벤트 순서는 `started → progress → answer.delta → result → done`이며 빈 결과·실패·중단·권한 변경을 구분합니다. 이벤트 이름·입력/응답·오류 원본은 [API 계약](../api/ai.md)에 있습니다. 내부 추론·도구 인자·계획 JSON은 사용자 스트림에 내보내지 않습니다.

같은 메시지·실행 ID를 다시 보내도 모델 실행을 중복 생성하지 않습니다. 실패 재시도는 원래 입력과 `expectedAttempt`를 비교하고 원자적으로 시도를 증가시킵니다. 여러 프로세스에서 같은 대화/검토 대상의 진행 실행 하나만 허용하며 이전 취소·완료는 새 시도를 변경하지 않습니다. 연결 단절·프로세스 장애·늦은 이벤트 처리에 대한 클라이언트 요구사항도 API 문서에 명시합니다.

전송 직전 관련 행과 현재 세션을 잠그고 실제 자료를 다시 읽습니다. 잠금은 ASGI 전송 경계까지만 유지하고 개별 전송을 3초로 제한합니다. 프로필 공개 변경과 본문 전송의 경쟁을 재현하는 DB 테스트가 있습니다. 모델 호출을 기다리는 동안에는 잠금·DB 세션을 유지하지 않습니다. 공개 철회가 전송 이후에 일어나거나 이미 전달된 바이트를 회수하는 문제까지 해결했다고 보지 않습니다.

권한·자료가 바뀌면 `invalidated`로 종료하며 클라이언트는 해당 답변 전체를 제거해야 합니다. 표시·복사 전 재검증이 실패하면 오래된 본문을 복사하지 않습니다. 지원자 프로필이 수정됐지만 현재 열람 관계가 유지되면 사용 버전과 현재 버전·`isStale`를 구분하고 새 검토를 안내합니다.

## 구현에 적용한 결정과 후속 작업

| ID | 이번 백엔드 구현 | 남은 작업 |
| --- | --- | --- |
| D-01 | 목적별 입력 필드 허용 목록, `store=False`, tracing 비활성화, 안전한 오류 로그 | 운영 조직의 제공자·로그/백업 보존 설정 확인 |
| D-02 | 짧은 전송 잠금·현재 권한 검사, 서버 근거 참조, 결과 해시 재검증 | 프론트의 전체 답변 무효화·화면 재진입·복사 연결, 운영 프록시 확인 |
| D-03 | 공유 실행 메타데이터, 상태/재시도/중단/검증 API, 기본 24시간 접근 만료, 정리 CLI, 원문 복원 없음 | 운영 정리 스케줄과 장애 관측 |
| D-04 | 기본 90초·계정 동시 2개·시간당 30시도·최대 3회 시도, 도구 8회·자료 30개·계획 모델 6회·입력 18,000토큰·출력 4,096토큰·reasoning low | 실제 데이터의 지연·비용·품질 평가 후 설정 조정 |
| D-05 | 프로필 완성 여부와 무관하게 공개 탐색 허용, 사용자 입력 조건만 적용, 비공개 본인 프로필 자동 개인화 없음 | 추가 개인화가 필요할 때 기능 명세 검토 |

한도는 무제한 실행을 막는 운영 기본값이며 카드 수·지원 자격 같은 제품 정책과 구분합니다. 입력 토큰 한도는 모델 호출별, 출력 토큰 한도는 제공자 호출별이며 전체 실행은 모델/도구 호출 수와 시간 제한으로도 제한합니다. 정확한 설정 범위는 [Settings](../../backend/app/core/config.py)가 원본입니다.

- [입력·이벤트 검사](../../backend/tests/unit/test_ai_contract.py): 1,000자·Unicode·권한 역할 입력 거부·맥락 상한·이벤트 페이로드·SSE OpenAPI.
- [HTTP·PostgreSQL 검사](../../backend/tests/integration/test_ai.py): 로그인/CSRF·타인 요청·비공개 지원자·실제 ID·중복·재시도·중단·세션 회수·전송 중 공개 철회·결과 위변조·프로필 버전·만료/정리.
- [실제 모델 수동 검사](../../backend/tests/manual/check_ai_model.py): 가상 자료만으로 Luna 도구 호출·구조화 출력·답변 스트리밍 확인. 일반 pytest는 유료 모델을 호출하지 않음.
- 로컬 DB 검증은 격리된 PostgreSQL 18에서 수행합니다. Docker를 사용할 수 없어 Compose 기준 PostgreSQL 17.11은 이번 로컬 실행에 사용하지 않았습니다. 운영 DB에는 migration을 적용하지 않았습니다.

실행·정리 명령은 [AI 로컬 실행](../development/local-development.md#ai-backend)을 참조합니다. 프론트 AC-16·23·26·28·33·34의 실제 화면 동작과 브라우저 E2E, 실제 지원자 자료를 사용한 추천 품질 평가는 완료로 표시하지 않습니다. 후속 사용자 요청에 따라 현재 작업 브랜치에 구현 커밋을 추가합니다. main 병합과 운영 배포는 별도 작업입니다.
