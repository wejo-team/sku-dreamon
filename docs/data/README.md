# 개발 데이터

개발·시연 데이터의 제작 기준과 버전을 관리합니다. 원본 자료와 DB 덤프는 저장소에 넣지 않습니다. 테이블·제약은 [DB 설계](../database/README.md), 제품 동작은 [기능 명세](../specs/README.md), 서버 준비는 [로컬 실행](../development/local-development.md)이 원본입니다.

| 문서 | 읽는 때 |
| --- | --- |
| [시연 데이터 제작과 운영](demo-dataset.md) | 공모전·팀 분포를 구성하거나 시연을 준비하고, 진단·백업·재생성을 할 때 |
| [데이터 버전과 변경 이력](versions.md) | 제작 규칙의 변경 범위, 버전별 집계와 재현 조건을 확인할 때 |
