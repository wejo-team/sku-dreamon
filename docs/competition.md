소프트웨어학과 × 전자컴퓨터공학과 연합 프로그래밍 공모전에 참가하는 15조 웨조의 제출·일정 안내입니다. **2026-11-01에 전달받은 회장단 최신 공지 3건을 Notion의 기존 안내보다 우선**하여 정리했습니다. 날짜와 시각은 한국 시간(KST, UTC+9) 기준입니다.

## 1차 제출 마감과 탈락 조건

**최종 제출 기한: 2026년 11월 1일(일) 오전 11시 59분까지.**

기한을 넘기면 예외 없이 자동 탈락하며, 기한 이후 추가 제출은 받지 않습니다. 아래의 영상 길이, 보고서 사진 크기·개수, 항목별 글자 수, 링크·접속 정보 기재, GitHub 공개 설정, 배포 서비스 정상 접속 중 **하나라도 지키지 않으면 예외 없이 자동 탈락**합니다.
