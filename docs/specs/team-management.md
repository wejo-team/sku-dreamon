# 팀장 전용 관리 기능

- 구현 상태: 예정
- 명세 검토: [PR #17](https://github.com/wejo-team/sku-dreamon/pull/17)
- 구현 작업: 미등록

## 목적과 사용자

팀장이 팀 정보와 모집 상태를 직접 관리할 수 있도록 한다. 팀장과 일반 팀원의 권한을 구분하여 각 사용자에게 필요한 기능을 제공한다.

## 범위

포함:
- 팀장 전용 관리 기능 제공
- 팀 정보 수정
- 팀 모집 마감
- 팀장과 일반 팀원의 관리 권한 구분

미포함:
- 팀장 위임 및 변경 기능
- 팀원 강제 탈퇴 기능
- 팀 삭제 기능

## 사용자 흐름과 동작

1. 사용자가 팀 상세 화면에 진입한다.
2. 팀장은 팀 정보 수정 및 모집 마감 버튼을 확인할 수 있다.
3. 팀 정보 수정 버튼을 선택하여 수정 가능한 정보를 변경하고 저장한다.
4. 모집 마감 버튼을 선택하여 모집 상태를 마감으로 변경한다.
5. 일반 팀원은 팀 정보를 확인할 수 있지만 팀장 전용 관리 기능은 사용할 수 없다.

## 정책과 예외

- 팀 관리 기능은 해당 팀의 팀장에게만 허용한다.
- 권한이 없는 사용자의 관리 기능 실행은 차단한다.
- 모집 마감 이후 신규 지원 및 초대 가능 여부는 모집 정책에 따른다.
- 정보 수정이나 모집 상태 변경에 실패하면 실패 사실을 안내한다.
- 이미 모집이 마감된 팀의 상태를 중복 변경하지 않도록 한다.

## 완료 조건

- [ ] AC-01: 팀장은 팀 상세 화면에서 관리 기능을 확인할 수 있다.
- [ ] AC-02: 팀장은 팀 정보를 수정하고 저장할 수 있다.
- [ ] AC-03: 팀장은 모집 상태를 마감으로 변경할 수 있다.
- [ ] AC-04: 일반 팀원에게 팀장 전용 관리 기능이 제공되지 않는다.
- [ ] AC-05: 권한이 없는 사용자는 관리 작업을 실행할 수 없다.
- [ ] AC-06: 변경 작업 실패 시 실패 결과를 확인할 수 있다.
