# 사람 탐색에서 팀 초대 기능

- 구현 상태: 예정
- 명세 검토: [PR #17](https://github.com/wejo-team/sku-dreamon/pull/17)
- 구현 작업: 미등록

## 목적과 사용자

사용자가 사람 탐색에서 함께할 사람을 발견했을 때 해당 사용자를 자신이 관리하는 팀으로 초대할 수 있도록 한다. 이를 통해 팀에 필요한 인재를 직접 탐색하고 모집할 수 있도록 한다.

## 범위

포함:
- 사람 탐색 화면에서 팀 초대 기능 제공
- 초대할 대상 팀 선택
- 초대 전송 결과 안내
- 초대받은 사용자의 초대 확인 및 응답 기능

미포함:
- AI 기반 인재 추천 알고리즘 개선
- 사용자 간 채팅 기능
- 초대 수락 이후 팀원 확정 절차 자체의 변경

## 사용자 흐름과 동작

1. 사용자가 사람 탐색 화면에서 함께할 사람을 찾는다.
2. 해당 사용자의 프로필에서 팀 초대 기능을 선택한다.
3. 초대할 수 있는 팀이 여러 개라면 대상 팀을 선택한다.
4. 초대 내용을 확인하고 전송한다.
5. 초대 전송 결과를 확인한다.
6. 초대받은 사용자는 초대 내용을 확인하고 수락하거나 거절한다.
7. 수락 이후 추가 합류 절차가 필요한 경우 해당 절차를 안내받는다.

## 정책과 예외

- 초대 권한이 있는 사용자만 초대를 보낼 수 있다.
- 모집이 마감된 팀에는 신규 초대를 보낼 수 없다.
- 동일 팀의 유효한 초대가 중복 생성되지 않도록 한다.
- 이미 합류한 사용자는 다시 초대할 수 없다.
- 초대 수락이 곧바로 팀원 확정을 의미하는지는 별도 정책에 따른다.
- 초대 전송에 실패하면 실패 사실을 안내한다.

## 미정 사항

- 팀 초대 권한은 팀장에게만 부여할 것인가?
- 초대 유효기간과 만료 후 처리 방식은 무엇인가?
- 초대 수락 시 즉시 팀원으로 확정되는가?
- 거절한 사용자에게 재초대할 수 있는가?
- 팀의 최대 인원이 충족된 경우 초대를 제한할 것인가?
