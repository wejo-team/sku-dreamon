# 현재 팀원 정보 확인

- 구현 상태: 예정
- 명세 검토:  [PR #17](https://github.com/wejo-team/sku-dreamon/pull/17)
- 구현 작업: 미등록

## 목적과 사용자

사용자가 팀 상세 화면에서 현재 합류한 팀원의 이름과 프로필을 확인할 수 있도록 한다. 이를 통해 함께 활동할 팀원을 파악하고 팀 활동을 시작하기 전에 서로를 이해할 수 있도록 한다.

## 범위

포함:
- 팀 상세 화면에서 현재 팀원 목록 제공
- 팀원의 이름 및 프로필 정보 표시
- 팀원 프로필 상세 화면으로 이동하는 기능 검토

미포함:
- 팀원 간 채팅 기능
- 팀원 평가 및 리뷰 기능
- 선발 대기자 및 합류 미확정 사용자 표시

## 사용자 흐름과 동작

1. 사용자가 팀 상세 화면에 진입한다.
2. 현재 팀에 합류한 팀원 목록을 확인한다.
3. 각 팀원의 이름과 프로필 정보를 확인한다.
4. 프로필 상세 화면이 제공되는 경우 팀원을 선택하여 추가 정보를 확인한다.

## 정책과 예외

- 실제 합류가 확정된 사용자만 현재 팀원 목록에 표시한다.
- 선발되었으나 합류가 확정되지 않은 사용자는 현재 팀원과 구분한다.
- 공개가 허용된 프로필 정보만 표시한다.
- 팀원이 없는 경우 빈 목록 상태를 안내한다.
- 탈퇴하거나 합류가 취소된 사용자는 현재 팀원 목록에서 제외한다.
