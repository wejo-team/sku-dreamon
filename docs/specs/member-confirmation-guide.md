# 선발 이후 팀원 확정 과정 안내

- 구현 상태: 예정
- 명세 검토: PR 링크
- 구현 작업: Issue 또는 PR 링크

## 목적과 사용자

지원 결과에서 선발된 사용자가 실제 팀원으로 확정되기까지 어떤 절차가 남아 있는지 이해할 수 있도록 한다. 팀장과 지원자가 다음에 해야 할 행동을 쉽게 파악하고 관련 기능으로 이동할 수 있도록 한다.

## 범위

포함:
- 선발과 최종 팀원 확정 상태 구분
- 선발 이후 진행해야 할 절차 안내
- 관련 기능으로 이동할 수 있는 바로가기 제공

미포함:
- 면접 및 1:1 대화 기능 자체의 신규 구현
- 팀원 확정 절차 및 승인 정책의 변경

## 사용자 흐름과 동작

1. 사용자가 지원 결과 화면에서 선발 결과를 확인한다.
2. 선발된 사용자는 선발 이후 팀원 확정까지 필요한 절차를 안내받는다.
3. 사용자는 안내에 따라 팀장과의 대화, 면접, 합류 의사 전달 등 필요한 행동을 진행한다.
4. 관련 기능이 제공되는 경우 바로가기를 통해 해당 화면으로 이동한다.
5. 팀원 확정 기능이 제공되는 경우 최종 확정 상태를 확인한다.

## 정책과 예외

- 선발 상태와 최종 팀원 확정 상태를 구분한다.
- 실제 제공되는 기능에 대해서만 바로가기를 제공한다.
- 확정되지 않은 절차를 필수 절차인 것처럼 안내하지 않는다.

## 완료 조건

- [ ] AC-01: 선발 결과 화면에서 선발이 최종 팀원 확정을 의미하지 않음을 확인할 수 있다.
- [ ] AC-02: 선발 이후 필요한 절차를 안내받을 수 있다.
- [ ] AC-03: 관련 기능이 제공되는 경우 바로가기를 통해 해당 기능으로 이동할 수 있다.
- [ ] AC-04: 아직 제공되지 않는 기능을 이용할 수 있는 것처럼 안내하지 않는다.

- 1:1 대화, 면접, 합류 의사 확인 중 실제로 제공하는 기능은 무엇인가?
- 최종 팀원 확정은 누가 어떤 방식으로 결정하는가?
