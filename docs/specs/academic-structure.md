# 대학·학부·전공 분류

- 구현 상태: 예정
- 명세 검토: [PR #14](https://github.com/wejo-team/sku-dreamon/pull/14), PDF 대조·명세 연결 보완 [PR #17](https://github.com/wejo-team/sku-dreamon/pull/17)
- 구현 작업: 미등록
- 변경 검토: 2026-10-18 공식 디자인·LLM 추천 반영, 이 변경 PR에서 사람 검토 대기

서경대학교 학사 분류를 기획 원문에서 옮긴 초안입니다. 아래 목록은 원문 보존용 이관 목록이며, 적용 학년도와 공식 자료 전체와의 일치는 아직 확정되지 않았습니다.
입력 필수 여부·공개 범위는 [프로필](profile.md), 코드·변경 이력 정책은 [공통 데이터 관리](profile-options.md#catalog-management)에 둡니다.

## 목적과 범위

사용자가 자신의 대학·학부·학과·전공을 일관된 계층에서 선택할 수 있게 합니다. 학사 목록은 명시적 참가 자격·팀 모집 조건을 확인할 때 사용하며, 학년·전공만으로 사람의 일반적인 우수성을 판단하지 않습니다. LLM 추천으로의 전환이 학사 정보 공개 범위를 확대하지 않습니다. 항목별 적용 범위와 원문의 미정 사항은 [추천 필수 조건](matching.md#eligibility)을 따릅니다.

<a id="selection-flow"></a>

## 선택 흐름

| 단계 | 선택 방식 | 처리 규칙 |
| --- | --- | --- |
| 1. 단과대학 | 단일 선택 | 선택한 대학에 해당하는 학부·학과만 표시 |
| 2. 학부·학과 | 단일 선택 | 독립 학과라면 이 단계에서 종료 |
| 3. 세부전공 | 조건부 단일 선택 | 세부전공이 있는 학부에만 표시; 미배정 상태 고려 |

- 세부전공이 없는 학부·학과는 마지막 선택 단계를 생략합니다.
- 자유전공학부의 전공 미배정 상태를 지원합니다.
- 동일 이름 전공이 여러 학부에 있어도 원문 목록의 소속 관계를 임의로 합치지 않습니다.
- 학부별 선택 가능 전공과 미배정 상태의 적용 범위는 검증·정책 결정이 필요합니다.

<a id="selection-policy"></a>

## 새 선택과 기존 과거 소속

[이슈 #42의 결정](https://github.com/wejo-team/sku-dreamon/issues/42#issuecomment-6234780726)에 따라 **새로운 소속 선택에는 현행 목록만 사용하고, 이미 저장된 과거 소속은 유지**합니다. 신규 입력과 소속 변경 모두 현행 항목만 선택할 수 있으며, 과거·비활성 항목의 코드를 새 선택값으로 저장할 수 없습니다.

| 상황 | 적용 정책 |
| --- | --- |
| 소속을 처음 등록 | 공식 자료로 확정한 현행 목록에서만 선택 |
| 기존 소속을 다른 소속으로 변경 | 새로 선택하는 값은 현행 목록으로 제한; 과거 항목으로 새 변경 불가 |
| 기존에 저장한 소속이 과거·비활성 항목이 됨 | 기존 값과 연결을 유지하며 삭제하거나 현행 항목으로 자동 치환하지 않음 |
| 과거 소속을 유지한 채 자기소개 등 다른 프로필 항목을 수정 | 기존 소속을 그대로 유지하며 현행 소속 재선택을 요구하지 않음 |

현행 목록의 실제 항목·적용 학년도·고유 코드·전공 관계는 아직 확정하지 않았습니다. 아래 31행 이관 표를 현행 선택 목록으로 승인하거나 전체 검증을 완료한 것으로 취급하지 않습니다. 이 결정은 가입 자격이나 대상 학번을 제한하는 정책이 아니며, 상위 대학·학부를 변경했을 때 기존 하위 선택값을 어떻게 처리할지는 ACADEMIC-05에서 별도로 정합니다.

<a id="maintenance"></a>

## 목록 유지 정책

- 학교 공식 학사 정보를 기준으로 갱신합니다.
- 코드와 표시명을 분리하고, 폐지·통합된 항목은 과거 기록 연결을 유지하도록 비활성화합니다. 구체 원칙은 [공통 데이터 관리](profile-options.md#catalog-management)를 따릅니다.
- [새 선택과 기존 과거 소속](#selection-policy)을 구분합니다. 비활성화한 과거 항목은 신규 선택에서 제외하되, 이미 저장된 사용자 소속을 삭제하거나 자동 치환하지 않습니다.
- 학사 분류에는 아직 고유 코드, 적용 학년도, 학부별 전공 배정 관계의 확정 자료가 없습니다.
- 이름만 같다는 이유로 소속 관계를 합치거나 원문의 행을 삭제하지 않습니다.

<a id="acceptance-criteria"></a>

## 완료 조건

- [ ] AC-01: 대학을 선택하면 그 대학에 속한 학부·학과만 선택 대상으로 나타난다.
- [ ] AC-02: 세부전공이 있는 학부에서는 세부전공을 선택할 수 있고, 독립 학과에서는 세부전공 단계를 생략한다.
- [ ] AC-03: 자유전공학부 사용자가 전공 미배정 상태를 나타낼 수 있다.
- [ ] AC-04: 같은 이름 전공의 서로 다른 학부 소속 관계를 구분할 수 있다.
- [ ] AC-05: 갱신된 학사 항목의 출처·적용 대상과 비활성화 이력을 확인하고, 기존 사용자 기록과의 연결을 유지할 수 있다.
- [ ] AC-06: 소속 최초 등록과 소속 변경에서 확정된 현행 목록의 항목만 새로 선택·저장할 수 있으며, 과거·비활성 항목의 코드를 새 선택값으로 저장할 수 없다. 실제 목록·코드·전공 관계를 확정한 뒤 검증한다.
- [ ] AC-07: 이미 저장된 소속이 과거·비활성 항목이 되어도 기존 값과 연결이 유지되고 삭제·현행 값으로의 자동 치환이 발생하지 않는다. 자기소개 등 다른 프로필 항목만 수정하면 소속이 그대로 유지되며 현행 소속 재선택을 요구하지 않는다.
