# 팀 모집과 지원

- 구현 상태: 예정
- 명세 검토: [PR #15](https://github.com/wejo-team/wejo-app/pull/15)
- 구현 작업: 미등록

## 목적과 사용자

사용자는 선택한 공모전에 참여할 팀을 만들거나 모집 중인 팀에 지원합니다. 팀장은 지원자를 검토·선발하고, 지원자는 본인의 결과를 확인합니다. 확정된 팀은 최소 팀 공간에서 공모전과 팀원 정보를 확인합니다.

## 범위

- 팀 생성, 모집글 작성·조회, 팀 목록·상세 조회를 제공합니다.
- 모집 조건 확인, 지원·취소, 본인의 지원 현황 조회를 제공합니다.
- 팀장의 지원자 검토·선발과 지원자의 결과 확인을 제공합니다.
- 팀 공간은 공모전 정보, 팀원, 모집·매칭 상태를 표시하는 최소 기능으로 구성합니다.
- 작업 분해·역할 제안과 일정 조율은 후속 스프린트 검토 범위입니다.
- 자체 채팅은 초기 범위에서 제외합니다. 외부 메신저 링크는 필요 시 제공하는 선택지이며 제공 여부는 미정입니다.

이 문서는 모집·지원·선발·확정의 동작과 상태를 함께 관리합니다. 공고 원문과 참가 자격·공고 마감은 [공모전 공고](contests.md), 지원자 정보의 공개 범위는 [프로필 공개 범위](profile.md#visibility)를 참조합니다. 추천 순위를 바꿀 때만 [팀·지원자 추천 점수](matching.md#team-scoring)를 함께 읽습니다.

## 팀과 모집글 정보

| 항목 | 용도 |
| --- | --- |
| 선택한 공모전 | 참여 대상 공모전과 연결 |
| 팀명·팀 목표 | 팀 목록·상세에서 팀을 식별하고 활동 목표 안내 |
| 필요한 역할 | 모집 역할과 필수·우대 조건 안내 |
| 모집 인원 | 모집 규모와 정원 확인 |
| 모집 마감 | 신규 지원 가능 기간 안내 |
| 활동 시간 구간 | 팀이 등록한 경우 활동 가능 시간의 비교 기준 |

역할·관심 분야 등 공통 선택지가 필요한 경우 [프로필 선택지](profile-options.md#choices)를 사용합니다. 모집글의 항목별 필수 여부와 모집 인원에 팀장을 포함하는지는 미정입니다.

## 사용자 흐름과 동작

### 팀 생성과 탐색

1. 사용자는 공모전을 선택하고 관련 팀 목록을 조회합니다.
2. 팀을 만들 때 공모전, 팀 목표, 필요한 역할, 모집 인원과 마감 정보를 입력해 모집글을 작성합니다.
3. 팀 목록·상세에서 팀명, 공모전명, 필요한 역할, 모집 인원, 마감일과 모집 조건을 확인합니다.
4. 추천된 팀을 보여주는 경우 실제 매칭 근거에 따른 이유를 함께 표시합니다.

### 지원과 결과 확인

1. 사용자는 모집 조건을 확인한 뒤 팀에 지원합니다.
2. 지원자는 내 지원 현황에서 지원 상태를 확인하고 지원을 취소할 수 있습니다. 취소 가능한 단계는 미정입니다. 취소·미선발 이후 팀장의 열람 권한은 [프로필 미정 사항 PROFILE-02](profile.md#open-questions)에서 검토합니다.
3. 팀장은 관리 화면에서 지원자 목록과 추천 후보를 확인하고 지원자를 검토·선발합니다.
4. 지원자는 본인의 선발·미선발 결과를 확인합니다.
5. 팀 결성 완료 기준을 충족하면 팀원이 확정됩니다. 선발 즉시 확정할지, 지원자가 수락한 뒤 확정할지는 미정입니다.

지원자 검토에는 [프로필 공개 정책](profile.md#visibility)에 따라 허용된 이름·희망 역할·관련 경험·역량·자기소개 등을 사용합니다. 가능 시간은 구체적인 개인 일정 대신 매칭에 필요한 겹침 정보만 표시합니다. 화면에 표시할 이름과 포트폴리오 공개 여부도 해당 정책을 따릅니다.

## 상태와 지원 가능 정책

<a id="recruitment-states"></a>

### 팀 모집 상태

| 상태 | 원문에서 정한 의미 |
| --- | --- |
| 모집 중 | 지원 가능, 팀 정보 확인 가능 |
| 지원자 검토 | 팀장이 지원자 목록을 확인하고 선발 진행 |
| 팀원 확정 | 팀원 구성이 확정된 상태 |
| 모집 마감 | 정원 충족 또는 팀장의 종료 처리로 신규 지원 불가 |

위 상태를 항상 순서대로 거친다고 확정하지 않습니다. 지원자 검토 중 신규 지원 가능 여부, 팀원 확정과 모집 마감의 관계, 모집 재개 가능 여부는 미정입니다.

<a id="application-states"></a>

### 지원자 상태

| 상태 | 사용자에게 보여줄 결과 |
| --- | --- |
| 지원 완료 | 해당 팀에 지원한 상태 |
| 검토 중 | 팀장이 지원자를 검토 중인 상태 |
| 선발 | 팀장이 지원자를 선발한 상태 |
| 미선발 | 선발되지 않은 상태 |
| 지원 취소 | 사용자가 지원을 취소한 상태 |

`선발`과 `팀원 확정`이 같은 시점인지는 아직 정하지 않았습니다. 수락 절차를 채택할 경우 필요한 상태와 동작을 추가로 확정해야 합니다.

<a id="application-rules"></a>

### 신규 지원과 중복 처리

- 모집 중이고 지원 기간이 남은 공고·팀에 지원할 수 있습니다.
- 마감된 공고, 모집 마감된 팀, 정원이 찬 팀에는 신규 지원할 수 없습니다.
- 동일 팀에 이미 지원한 사용자에 대해 중복 지원을 만들지 않습니다.
- 원문은 지원 취소·미선발 상태인 사용자도 중복 지원 대상에서 제외합니다. 이후 다시 지원할 수 있는 조건이나 시점은 제시하지 않아 미정으로 남깁니다.
- 참가 자격의 충족·미충족·확인 필요 판정은 [공모전 참가 자격](contests.md#eligibility)을 따릅니다. 확인 필요 상태의 실제 지원 허용 여부는 아직 정하지 않습니다.
- 정원 초과를 방지해야 하지만, 모집 인원 산정과 선발·수락 중 어느 시점에 정원을 차감할지는 미정입니다.

<a id="team-requirements"></a>

### 팀 조건과 추천 대상의 구분

- 팀은 모집 역할을 필수 조건 또는 우대 조건으로 정할 수 있습니다.
- 필수 역할을 희망 역할로 선택한 사용자만 해당 역할 조건을 통과한 지원자 추천 후보가 됩니다. 우대 역할은 후보 제외 조건이 아니라 추천 점수에 반영합니다.
- 실제 지원자 추천은 해당 팀에 지원 완료한 사용자만 평가합니다. 이 표현이 상태값 `지원 완료`만 뜻하는지, `검토 중` 지원자도 포함하는지는 미정입니다.
- 필수 역할 조건이 실제 지원 자체도 제한하는지는 원문에서 별도로 확정하지 않았습니다.
- 학년·전공 등의 팀 조건은 실제로 명시된 경우에만 적용하며, 경험이 적다는 이유만으로 초보자를 자동 제외하지 않습니다.

<a id="workspace"></a>

## 최소 팀 공간과 화면

| 화면 | 핵심 동작 |
| --- | --- |
| 팀 목록·상세 | 모집 조건과 팀 정보를 확인하고 지원 |
| 팀 생성·모집글 작성 | 공모전, 역할, 인원, 마감 입력 |
| 내 지원 현황 | 본인의 지원 상태와 결과 확인 |
| 팀장 관리 | 지원자 목록·추천 후보 확인, 선발 처리 |
| 팀 공간 | 확정된 팀원, 공모전 기본 정보, 모집·매칭 상태 표시 |

팀 공간의 정보 공개도 [프로필 공개 정책](profile.md#visibility)을 따릅니다. 초기 알림은 서비스 화면 안의 상태 표시로 처리하며 푸시 알림은 후속 검토 범위입니다.

<a id="acceptance-criteria"></a>

## 완료 조건

- [ ] AC-01: 사용자가 공모전을 선택해 팀을 만들고 모집글의 조건을 목록·상세에서 확인할 수 있다.
- [ ] AC-02: 지원 가능한 팀에 지원한 뒤 내 지원 현황에 해당 팀과 상태가 표시된다.
- [ ] AC-03: 지원자는 확정된 취소 허용 단계에서 지원을 취소하고 취소 상태를 확인할 수 있다.
- [ ] AC-04: 팀장이 해당 팀의 지원자를 검토·선발하고, 지원자가 본인의 결과를 확인할 수 있다.
- [ ] AC-05: 마감된 공고·팀이나 정원이 찬 팀에 신규 지원할 수 없다.
- [ ] AC-06: 동일 팀에 대한 중복 지원이 발생하지 않는다.
- [ ] AC-07: 확정된 팀 결성 완료 기준에 따라 팀원이 확정되고, 최소 팀 공간에 팀원·공모전·모집 및 매칭 상태가 표시된다.
- [ ] AC-08: 지원자 검토와 팀 공간에 표시하는 프로필 정보가 각 대상의 공개 범위를 넘지 않는다.

AC-03과 AC-07의 검증에는 아래 미정 사항의 확정이 선행되어야 합니다. 명세 작성만으로 완료 처리하지 않습니다.

<a id="open-questions"></a>

## 미정 사항

- 팀 결성 완료 시점: 팀장의 선발 시점 또는 선발된 지원자의 수락 시점.
- 모집 인원에 팀장을 포함하는지, 정원을 선발·수락 중 어느 시점에 차감하는지.
- 지원자 검토 중 신규 지원 가능 여부와 팀원 확정·모집 마감 사이의 상태 전이.
- 지원 취소 가능한 단계, 취소·미선발 이후 재지원 허용 여부와 조건.
- 참가 자격이 확인 필요인 사용자의 지원 허용 여부와 확인 절차.
- 팀 필수 역할이 실제 지원을 제한하는지와 `검토 중` 지원자의 추천 평가 여부.
- 모집글 항목별 필수 여부, 모집 조건 변경과 모집 재개 허용 여부.
- 외부 메신저 링크 제공 여부, 팀 공간을 열람할 수 있는 대상과 시점.
