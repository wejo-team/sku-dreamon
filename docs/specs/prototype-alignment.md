# 공식 디자인 기능·명세 대조

2026-10-19 [#77의 확정 결정](https://github.com/wejo-team/sku-dreamon/issues/77#issuecomment-6260435650)을 명세 → 디자인 → 배포 순서로 반영한 기록입니다. 정책 원본은 각 기능 명세이며, 이 문서는 검증한 디자인 범위와 남은 차이를 관리합니다. **디자인 일치와 실제 제품 구현 완료를 구분하며 AC 완료 체크는 변경하지 않습니다.**

## 추가 정책의 저장소 디자인 반영

**2026-10-21 추가 결정은 명세·DB·API 설계에만 반영했습니다.** [팀 모집 두 상태·명시적 지원 전이](team-recruitment.md#team-state-transitions), [공고 마감 전 기존 지원 선발](team-recruitment.md#selection-window), [종료 사유별 재지원·소속 중 신규 지원 금지](team-recruitment.md#reapplication), 팀 생성 시 대기 지원 폐기의 화면·서버 구현과 검증은 후속 작업입니다. 팀장의 선발 취소·강퇴·탈퇴·팀 삭제는 MVP에서 제공하지 않습니다. 아래 2026-10-19 디자인 검증 결과를 새 결정의 구현 근거로 사용하지 않습니다.

2026-10-19 사용자 결정은 [문서 PR #94](https://github.com/wejo-team/sku-dreamon/pull/94)로 먼저 정리하고, [저장소 디자인 `14d59b9`](https://github.com/wejo-team/sku-dreamon/tree/14d59b968b3f0faeb88ba54db94dfca796c2382d/design-reference)에 반영했습니다. 아래 변경은 로컬 코드·모바일 화면에서 검증했으며 **공유 GPT Sites v13에는 아직 배포하지 않았습니다.** 제품 API·DB·실제 LLM의 구현 완료를 뜻하지 않습니다.

최종 Vitest 14개 파일·214개 테스트, ESLint·Prettier·TypeScript·빌드를 통과했습니다. 320·390·430px에서 모집 재개 확인/취소·폐기 이력·기존 지원서 AI 검토와 후보 제외를 확인했습니다. [검증 기록과 스크린샷](../design/verification.md)에 근거를 정리했습니다.

## 모의 구현과 제품 구현의 경계

- 로그인은 공개 UI 확인 문자열 **`dreamondemo` / `DreamonReview2026!`**로 동작합니다. 실제 계정·비밀번호 해시·서버 세션이 아니며 가입/중복/알려진 취약 비밀번호 검사는 예시입니다.
- 프로필·팀·지원·알림·현재 AI 검토 결과는 해당 브라우저 메모리입니다. 화면 이동은 유지하지만 새로고침은 초기 상태로 돌아가고 다른 팀원과 공유하지 않습니다. 실제 영구 저장·권한·세션 만료·동시 정원 검증은 제품에서 구현합니다.
- 자연어 응답과 지원자 검토는 로컬 예시 정보로 작성합니다. 실제 LLM·추천 품질·외부 포트폴리오 수집은 없으며 내부 아키텍처는 TBD입니다.
- 날짜 예시는 2026-10-18에 고정합니다. 마감 판정 함수는 명세의 원문 시각/시간대 우선과 기본값을 사용하며 테스트에서는 경계 시각을 주입합니다. 운영 현재 시각 연결·수집/검수는 별도입니다.
- 번호 페이지·총결과 수는 메모리 집계이며 한 페이지 6개는 디자인 설정입니다. 조건·페이지 URL과 상세 복귀를 유지하되 이전 스크롤 복원·운영 페이지 크기·API/DB 조회는 별도입니다.
- 실제 모바일 보조 기술·서버 동시성·운영 계정·LLM 성능까지 검증한 결과로 해석하지 않습니다.

## 이전 공유 배포 v13에서 수행한 검증

- 명세별 작업과 독립 교차 검토 후 위 불일치를 수정했습니다. 제품 명세 AC 체크는 유지했습니다.
- Vitest **14개 파일·201개 테스트** 통과. 초과값 보존·Unicode 경계·비공개 신규 지원·기존 지원 유지·최신 검토·알림 중복/이력·추천 후보 변경·마감 시각 경계를 포함합니다.
- 전체 ESLint·Prettier·TypeScript·프로덕션 빌드 통과. 단일 JS 청크 500kB 초과 경고는 남습니다.
- [브라우저 스크립트][browser-check]에서 **320·390·430px** 주요 연결 흐름·가로 넘침·런타임 오류 검사 통과. 별도 **320·390px** 검사에서 주당 시간 네 구간 저장/취소, 1인 팀·상한 없는 27명 팀 생성, 가입 길이 오류/비밀번호 토글, AI 초과 입력 보존을 확인했습니다.
- 모바일 스크린샷을 직접 확인했습니다. AI 길이 오류와 입력창 외곽선의 겹침을 발견해 여백을 보완하고 다시 확인했습니다. 원격 화면 전체를 자동화한 것은 아니며 로컬 상호작용 검증과 배포 소스 일치·배포 성공을 결합한 결과입니다.
- 문서 원본 링크·앵커, 문서 빌드와 생성된 HTML 링크·자산 검사를 수행했습니다.
