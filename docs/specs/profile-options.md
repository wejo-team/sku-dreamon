# 프로필 선택지와 공통 코드

- 구현 상태: 예정
- 명세 검토: [PR #14](https://github.com/wejo-team/sku-dreamon/pull/14), PDF 대조·명세 연결 보완 [PR #17](https://github.com/wejo-team/sku-dreamon/pull/17)
- 구현 작업: 미등록
- 변경 검토: 2026-10-19 전체 프로필 공개 범위·현재 선택지와 입력 흐름 대조 및 [#77](https://github.com/wejo-team/sku-dreamon/issues/77)의 주당 참여 가능 시간 정책 반영, 이 변경 PR에서 사람 검토 대기

공통 선택지와 코드 관리 원칙을 옮긴 초안입니다. 필드의 필수 여부·단일/복수 입력은 [프로필 입력 항목](profile.md#fields), 대학·학부·전공 관계는 [학사 분류](academic-structure.md)에서 정의합니다.
목록 변경 작업에는 아래 필요한 분류와 관리 원칙만 읽습니다.

## 목적과 범위

사용자 입력, 추천, 검색 필터, 통계가 같은 분류와 코드 의미를 사용하도록 합니다.
이 문서는 선택 가능한 값과 공통 데이터 관리 원칙을 정의합니다. 공개 범위는 [프로필](profile.md#visibility), LLM 추천의 동작·미정 내부 설계는 [추천 매칭](matching.md)에서 관리합니다.

## 공통 선택지

아래 선택지 표시는 `추가 리스트 최종.md`에서 이관했으며, 희망 역할은 아래 [역할 목록 결정](#role-policy)에 따라 6개를 제공합니다. 원문에 코드값은 없으며 아래 이름을 코드로 사용한다는 뜻이 아닙니다. 원문의 요일별 시간 구간은 2026-10-19 [주당 참여 가능 시간 정책](#weekly-availability)으로 대체합니다.

| 항목 | 선택지 |
| --- | --- |
| 관심 분야 | IT·기술 / 경영·창업 / 디자인 / 사회·문화 / 환경 / 교육 / 미디어·콘텐츠 / 보건·의료 / 정책 / 공공 / 기타 |
| 희망 역할 | 기획 / 디자인 / 개발 / 마케팅 / 자료조사 / 발표 |
| 보유 역량 | 프로그래밍 / UI/UX / 데이터분석 / 영상 편집 / 문서 작성 / 서비스 기획 / 시장 조사 / 그래픽 디자인 / PPT 제작 / 데이터 시각화 / SNS 마케팅 / 콘텐츠 기획 / 발표·스피치 / 기타 |
| 주당 참여 가능 시간 | 5시간 미만 / 5~10시간 미만 / 10~20시간 미만 / 20시간 이상. 참여 중인 모든 프로젝트를 합산한 자기신고 예상 총량이며 단일 선택 |
| 학적 상태 | 재학 / 휴학 / 졸업 / 기타 |
| 학년 | 1학년 / 2학년 / 3학년 / 4학년 이상 / 해당 없음 |

원문 공통 표의 포트폴리오·관련 경험은 정해진 선택지 목록이 아니므로 [프로필 입력 항목](profile.md#fields)에서 입력 정책을 관리합니다.

### 희망 역할 목록

[이슈 #26의 결정](https://github.com/wejo-team/sku-dreamon/issues/26#issuecomment-6234780296)에 따라 희망 역할은 **기획·디자인·개발·마케팅·자료조사·발표의 6개만 제공**하고 ‘기타’는 포함하지 않습니다. 희망 역할용 기타 선택지·보충 설명 입력은 제공하지 않으며, 관심 분야·보유 역량·학적 상태 등 다른 분류의 기타 선택지는 유지합니다.

필수·복수 선택 여부는 [프로필 입력 항목](profile.md#fields)을 따릅니다. 이 결정은 선택 가능한 역할의 범위를 정하며, [모집 역할 불일치만으로 추천·지원을 제한하지 않는 정책](matching.md#policy-decisions)을 바꾸지 않습니다. LLM 기반 추천으로 전환하며 기존 역할 점수·가중치 산식은 제외합니다.

## 주당 참여 가능 시간

2026-10-19 사용자 결정([#77](https://github.com/wejo-team/sku-dreamon/issues/77))에 따라 프로필의 요일별 3시간 가능 구간을 폐기하고, **참여 중인 모든 프로젝트를 합산한 주당 참여 가능 시간**을 받습니다. 팀장이 지원자를 검토할 때 참고하는 자기신고 예상 총량이며, 특정 팀에 제공하기로 약정한 시간이 아닙니다.

- [프로필 입력 항목](profile.md#fields)의 권장 입력을 유지하며 필수로 강제하지 않습니다. 아래 네 구간 중 하나를 선택하며 숫자를 직접 입력하지 않습니다. 미입력은 별도 상태이며 가장 낮은 구간으로 간주하지 않습니다. 미입력 총량이나 구체적인 요일·시각을 추정하지 않습니다.
- 여러 팀에 지원해도 프로필의 같은 값을 사용합니다. 변경을 저장하면 [현재 프로필을 사용하는 지원 검토](profile.md#application-profile)에 반영하며, 팀별 확정 일정이나 약속을 자동 수정하지 않습니다.
- 팀장이 이 값을 각 팀에 각각 사용할 수 있는 시간, 다른 활동을 차감한 잔여 시간, 일정 확보 또는 팀원 간 일정 교집합의 보장으로 해석하지 않도록 의미를 안내합니다.
- 등록값은 [전체 프로필 공개 상태와 지원 팀장 예외](profile.md#visibility)에 따라 표시합니다. 공개 범위와 모델 전송 권한은 별개이며, LLM 입력 범위는 추천 명세의 미정 사항을 따릅니다. 시간 점수·겹침 비율·미입력 대체 점수는 제공하지 않습니다.
- 팀의 구체적인 일정 조율은 팀 공간의 후속 기능 구상입니다. 현재 미구현이며 상세 입력·동의·변경·시간대 정책은 TBD입니다. 프로필의 주당 총량 입력을 팀 일정 기능의 구현이나 약속으로 간주하지 않습니다.

2026-10-19 추가 사용자 결정으로 입력 구간과 경계를 다음과 같이 정합니다.

| 선택지 | 경계 의미 |
| --- | --- |
| 5시간 미만 | 예상 총량이 5시간보다 적음 |
| 5~10시간 미만 | 5시간 이상, 10시간 미만. 정확히 5시간이면 이 구간 |
| 10~20시간 미만 | 10시간 이상, 20시간 미만. 정확히 10시간이면 이 구간 |
| 20시간 이상 | 20시간 이상. 정확히 20시간이면 이 구간 |

한 프로필에는 한 구간만 선택합니다. 구간은 자기신고 참고 정보의 표현이며 실제 투입 시간 측정값이나 약정이 아닙니다. 구간별 고유 저장 ID와 기존 요일별 슬롯 데이터의 전환·재입력 처리는 OPTIONS-07에 남깁니다.

이 정책은 #77의 앞선 F10 한국시간·요일별 3시간 슬롯 합의를 **프로필 입력에 한해 대체**합니다. 그 합의를 팀 일정 시간대 정책으로 자동 적용하지 않습니다. 기존 `time-slots` 앵커는 과거 링크 호환을 위해 유지합니다.

## 코드와 공통 데이터 관리

| 원칙 | 정책 |
| --- | --- |
| 코드·표시명 분리 | 각 항목은 변경되지 않는 고유 코드로 저장하고 화면에는 표시명을 출력. 표시명 변경으로 기존 데이터 의미가 바뀌지 않아야 함 |
| 단일 관리 | 학적 상태·학년·단과대학·전공·학과·관심 분야·희망 역할·보유 역량을 공통 기준 목록으로 관리. 화면별 별도 목록 금지 |
| 관심 분야 정의 | 관리자가 정의한 공통 분류를 사용. 관리자 편집 화면·관리 기능의 구현 범위는 원문에 정의되지 않음 |
| 입력 형태 | 필드별 단일·복수 값 구분은 프로필 명세를 따름. 주당 참여 가능 시간은 정해진 네 구간 중 단일 선택이며 미입력을 허용 |
| 기타 | 기타를 제공하는 분류에서 기타를 선택한 경우에만 보충 설명을 입력할 수 있음. 희망 역할에는 미제공. 표준 코드와 분리해 저장하며 자동으로 새 표준 분류로 취급하지 않음 |
| 미입력·미확인 | 불일치로 간주하지 않고 별도 상태로 저장. 필수 자격을 확인할 수 없으면 자동 통과시키지 않고 확인 필요로 구분하는 [추천 필수 조건](matching.md#eligibility)을 따름 |
| 공통 활용 | 공모전·팀·지원자 추천, 검색 필터, 통계 집계에서 동일한 표준 코드와 분류 의미를 사용 |
| 학사 정보 갱신 | 학교 공식 학사 정보를 기준으로 갱신. [학사 선택 정책](academic-structure.md#selection-policy)에 따라 새 선택은 현행 목록만 허용하고 폐지·통합 항목은 비활성화하여 저장된 과거 기록과 연결 유지 |
| 변경 이력 | 목록의 추가·수정·비활성화 날짜와 변경 사유 기록. 추천 내부 설계는 [LLM 추천의 TBD](matching.md#open-questions)로 구분 |

공식 학사 목록의 이관 값과 출처 검증 상태는 [학사 목록](academic-structure.md#catalog)에서 관리합니다. 현재 표는 코드가 부여된 운영 데이터나 구현된 설정 파일이 아닙니다.

## 현재 디자인 레퍼런스

[현재 버전 대조표](prototype-alignment.md)의 v12 입력 화면은 위 관심 분야·희망 역할·역량·학적 상태·학년 선택지와 같습니다. **시간 입력은 아직 요일별 3시간 구간이며 새 주당 참여 가능 시간 정책을 반영하지 않았습니다.** 화면은 표시 문자열을 사용하며, 운영용 고유 코드·목록 버전·변경 이력을 구현한 것은 아닙니다.

| 현재 화면 | 확인할 동작과 정책 구분 |
| --- | --- |
| 관심 분야·희망 역할·역량 | 체크박스로 복수 선택합니다. 관심 분야·희망 역할은 필수, 역량은 권장이며 희망 역할에는 기타가 없습니다. |
| 기타 관심 분야·기타 역량 설명 | 각각 기타 선택 시에만 선택 입력을 표시합니다. 기타를 해제한 상태로 프로필을 저장하면 해당 보충 설명도 비웁니다. 이 문구가 표준 선택지에 새 항목을 추가하지 않으며 학적 상태의 기타에는 보충 입력이 없습니다. 최종 적용 항목·입력 제한은 OPTIONS-03에서 검토합니다. |
| 기존 활동 시간 설정 | v12는 현재 입력값에서 팝업 초안을 시작하고 요일별 3시간 구간을 복수 선택합니다. 선택 지우기로 전체 시간 초안을 비울 수 있습니다. 폐기한 입력 방식의 현황이며 주당 총량 정책의 구현 근거가 아닙니다. |
| 시간 선택 적용·취소 | `선택 적용`은 편집 중인 프로필에만 반영하며 최종 `변경사항 저장`이 필요합니다. 팝업 취소·Escape·바깥 닫기는 미적용 초안을 버리고, 다시 열면 편집 중인 값에서 시작합니다. 프로필 편집 자체를 취소하면 저장값은 유지됩니다. |

활동 시간의 화면 표기 `선택`은 필수가 아니라는 의미이며 권장 입력 정책을 바꾸지 않습니다. 현재 메모리 모델은 요일·구간을 이어 붙인 문자열을 사용하지만, 이 표현을 새 주당 총량의 값이나 실제 API·DB 저장 형식으로 사용하지 않습니다. 기존 구간을 합산하면 사용자의 자기신고 주당 예상 총량과 같다고 보장할 수 없으므로 주당 총량이 입력된 것으로 취급하지 않습니다. 시간 겹침 점수·비율은 제공하지 않습니다.

<a id="acceptance-criteria"></a>

## 완료 조건

- [ ] AC-01: 같은 분류 항목을 프로필·추천·검색에서 조회할 때 동일한 코드 의미와 표시명을 사용한다.
- [ ] AC-02: 표시명을 변경해도 기존 사용자 선택값의 의미와 연결이 유지된다.
- AC-03(폐기): 요일별 3시간 구간 선택·자정 경계 확인 조건은 2026-10-19 주당 참여 가능 시간 정책으로 대체합니다. 번호는 과거 참조용으로 남기며 새 조건은 AC-08을 사용합니다.
- [ ] AC-04: 기타를 제공하는 분류의 보충 설명은 표준 코드와 분리되며 설명을 입력해도 공통 선택지에 자동 추가되지 않는다. 희망 역할에는 기타 선택지·보충 설명 입력이 제공되지 않는다.
- [ ] AC-05: 미입력·미확인 값이 명시적인 불일치 값과 구분된다.
- [ ] AC-06: 학사 항목이 폐지·통합되어 비활성화돼도 과거 사용자 기록과의 연결, 변경 날짜·사유를 확인할 수 있다.
- [ ] AC-07: 희망 역할로 기획·디자인·개발·마케팅·자료조사·발표만 선택·저장할 수 있고 ‘기타’를 추가로 선택·저장할 수 없다. 다른 분류의 기타 선택지는 유지하며, 모집 역할과 다르다는 이유만으로 추천 후보를 제외하거나 지원을 막지 않는다.
- [ ] AC-08: 주당 참여 가능 시간은 참여 중인 모든 프로젝트를 합산한 자기신고 예상 총량으로 안내하며, 특정 팀의 약정·잔여 시간이나 일정 확보·교집합 보장으로 표시하지 않는다. 미입력을 허용하고 이를 가장 낮은 구간으로 취급하지 않는다.
- [ ] AC-09: 주당 참여 가능 시간은 `5시간 미만`, `5~10시간 미만`, `10~20시간 미만`, `20시간 이상` 중 하나만 선택한다. 정확히 5시간·10시간·20시간은 각각 두 번째·세 번째·네 번째 구간으로 안내하며 숫자 직접 입력은 제공하지 않는다.

## 미정 사항

| ID | 결정할 내용 |
| --- | --- |
| OPTIONS-02 | 분야·역할·역량의 고유 코드와 표기 정규화, 초기 목록의 적용 버전. 폐기한 프로필 요일·시간 슬롯은 대상에서 제외 |
| OPTIONS-03 | 기타를 제공하는 분류의 보충 설명 적용 항목·입력 필수 여부·길이 제한. 희망 역할은 기타 미제공으로 제외 |
| OPTIONS-04 | 경험 입력에 사용할 분야 분류와 자유서술의 관계. 기존 점수 계산용 직접·인접 관계나 역할·역량 대응 점수표는 요구하지 않음 |
| OPTIONS-07 | 주당 참여 가능 시간 구간의 고유 저장 ID, 기존 요일별 슬롯 데이터의 전환·재입력 처리. 기존 구간을 합산해 자기신고 주당 총량이 입력된 것으로 자동 취급하지 않음 |

OPTIONS-01은 [희망 역할 6개·기타 제외](#role-policy)로 반영했습니다. 코드·표기 정규화와 나머지 미정 사항은 위 후속 항목에서 정합니다.

기존 OPTIONS-05의 프로필 슬롯 시간대·주 경계·팀 슬롯 일치 여부는 주당 총량 정책으로 대체해 프로필 입력 요구에서 제외합니다. 팀 공간의 후속 일정 기능은 여전히 미구현·상세 TBD이며, 이 변경으로 시간대나 일정 입력 방식을 확정하지 않습니다.

OPTIONS-06의 입력 형태·허용값은 2026-10-19 [주당 참여 가능 시간의 네 구간 단일 선택](#weekly-availability)으로 반영했습니다. 권장 입력을 유지하며 미입력을 낮은 구간과 구분합니다. 이 결정이 구간 저장 ID나 기존 슬롯 데이터 전환 방식까지 확정하지는 않습니다.
